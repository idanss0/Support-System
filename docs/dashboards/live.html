These buttons exist only in the demo. The real screen refreshes on its own every 30-60 seconds from the DW, and shows the red warning when its data is more than 5 minutes old.

Definitions used on this screen
Open P1
An open case whose current priority is P1.
SLA at risk
An open milestone whose target time is within 60 minutes (P1/P2) or 4 hours (P3/P4). The SLA comes from Salesforce as is; the screen does not recalculate it.
Waiting for pickup
An open escalation request whose owner is a queue, not a person. The wait counts from when the request was opened.
Tier
The tier of the latest open request on the case, or Tier 1 when there is none. For a request, the tier it was sent to.
Case and request links
In the real screen, each number opens the record in Salesforce. Here they only show a message.
